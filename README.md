# 🛒 Supermarket Sales Analysis Dashboard

## 📌 Project Overview
The **Supermarket Sales Analysis Dashboard** is an interactive Excel-based data analytics project designed to analyze supermarket sales performance and identify meaningful business insights.

The dashboard provides a clear overview of sales revenue, average sales, product visibility, outlet performance, product categories, and location-based sales distribution. It helps users understand sales patterns and make data-driven business decisions.

## 🎯 Project Objectives
- Analyze overall supermarket sales performance.
- Identify high-performing outlet types and locations.
- Compare sales across different product categories.
- Analyze Low Fat and Regular product sales.
- Understand the relationship between item visibility and sales.
- Track key performance indicators (KPIs).
- Support better business decision-making through interactive visualization.

## 🛠️ Tools & Technologies
- **Microsoft Excel**
- Pivot Tables / Excel Formulas
- Excel Charts
- Interactive Dashboard
- Data Cleaning and Data Analysis

## 📊 Dashboard Features

### 1. Overall Sales Performance
Displays important KPIs:
- Total Sales
- Average Sales per Record
- Average Item Visibility

### 2. Sales Analysis
- Sales by Outlet
- Sales by Outlet Establishment Year
- Sales by Product Category
- Sales by Outlet Type
- Sales by Outlet Location

### 3. Product Analysis
- Low Fat vs Regular product sales
- Top four product categories compared with the remaining categories
- Average sales per product category

### 4. Item Visibility Analysis
- Visibility-based sales comparison
- Distribution of sales per record
- Average sales across different visibility bands

### 5. Interactive Filters
The dashboard includes interactive dropdown filters for:
- Outlet Type
- Location Tier
- Item Fat Content

Users can select different filter options to explore the corresponding sales performance.

## 📁 Dataset Information

The workbook contains a dataset with approximately **8,523 sales records** and includes the following fields:

- Item Fat Content
- Item Identifier
- Item Type
- Outlet Establishment Year
- Outlet Identifier
- Outlet Location Type
- Outlet Size
- Outlet Type
- Item Visibility
- Item Weight
- Sales
- Rating

Additional calculated columns support data cleaning, filtering, and dashboard analysis.

## ⚙️ How to Use
1. Download the Excel workbook from this repository.
2. Open it using Microsoft Excel.
3. Navigate to the **Dashboard** worksheet.
4. Use the dropdown filters to select outlet type, location tier, and item fat content.
5. Explore the charts and KPI values.
6. Navigate to the **Analysis** worksheet to view supporting calculations.
7. Navigate to the **Data** worksheet to explore the dataset.

**Note:** Enable editing and automatic formula calculation in Excel to ensure the dashboard updates correctly when filters are changed.
